如何使用

1

添加「图像 API」槽位

打开 Dot. App → 内容工坊 → 添加「图像 API」到设备循环任务。

2

获取 API 密钥

Dot. App → 更多 → API 密钥 → 创建，复制 dot_app_ 开头的密钥。

3

复制设备序列号

Dot. App → 更多 → 设备列表 → 选择设备 → 复制 12 位设备序列号。

4

注册订阅

点击上方「立即注册」，填入密钥、序列号和城市。之后每天自动推送，无需任何操作。
