使用指南

从零到每天收到推送，大约 3 分钟。设置一次，之后不用再管。

开始之前

  • 一台 Dot. 墨水屏设备
  • 手机上的 Dot. App（用来操作设备）

不需要电脑，不需要安装任何软件。推送在服务端完成，你的电脑开不开机都不影响。

设置步骤

1

在 Dot. App 里添加「图像 API」槽位

这一步不能跳过。设备只有在循环任务里放了「图像 API」，才有位置显示推送过来的图片。

打开 Dot. App › 进入你的设备 › 内容工坊 › 循环任务 › 添加「图像 API」 › 保存

部分版本的 App 里，「内容工坊」显示为「内容管理」。

2

创建 Dot. API 密钥

这串密钥用来让服务端把图片推到你的设备上。

打开 Dot. App › 底部「更多」 › API 密钥 › 创建 API Key › 复制

复制到的是一串 dot_app_ 开头的字符。找不到「API 密钥」入口的话，先把 Dot. App 更新到最新版。

3

复制设备序列号

用来指定推送的目标设备，如果你只有一台设备，记这一次就行。

打开 Dot. App › 底部「更多」 › 头像下方的设备列表 › 选择你的设备 › 下滑找到「设备序列号」 › 点击复制

是一串 12 位字母数字。

4

在网页上注册

把刚才拿到的密钥和序列号填进注册页，再选一下你所在的城市（列表里没有的话可以填经纬度）。

提交之后：屏幕上会立刻出现第一条诗词天气，稍等片刻自动刷新。页面会跳转到你的专属管理页，请把这个链接存进收藏夹，以后换城市、暂停推送都要用它。

去注册

注册之后

  • 每天上午 9 点自动推送，你不用做任何事，电脑也不用开。
  • 推送内容是当天实况天气 + 一首应景的古诗词，底部还有日期、农历和节气。
  • 同一座城市最近 20 天不会重复推同一首诗。
  • 服务端的改进（诗词库扩充、版式优化）自动生效，不用重新注册。

管理你的订阅

用注册后生成的管理链接，你可以：

  • 立即推送一次 —— 想马上看看效果
  • 更换城市 —— 出差、搬家之后改一下
  • 注销订阅 —— 停止推送并删除你的订阅记录

管理链接丢失了？出于安全考虑本服务无法找回，需要重新注册一次。

数据与密钥说明

订阅版要把 Dot. API 密钥交给服务端。这里把存什么、风险在哪一次说清，你再决定用不用。

  • 存什么 —— Dot. API 密钥、设备序列号、城市（经纬度）、注册时间，以及每天推送的诗词记录
  • 为什么必须存密钥 —— 推送由服务端每天定时发起，密钥只能留在服务端，没法只存在你自己手里
  • 存在哪 —— 服务端的一个数据库文件里，只有服务端程序会读到它
  • 风险是什么 —— 密钥是明文保存的。这是个人的业余项目，没有做过任何安全认证，也不承诺绝对不泄露。真被拿到，对方能往你的设备推内容，但读不到你的账号、其他设备或任何别的数据
  • 你随时能收回 —— 在 Dot. App 或网页端 dot.mindreset.tech/panel?tab=api-keys 删掉这枚密钥，它立刻失效，我们再也推不了；那里还能看到它的最后使用时间
  • 注销即真删 —— 点注销后，密钥、设备序列号、经纬度和推送历史都会从服务端删除，不留备份

说白了：能接受就用订阅版，最省事，电脑不用开；不能接受就别交密钥，走下面那条自建的路。

不想交密钥？自己部署一份

把这份程序跑在你自己那里，密钥只存在你自己的机器上，不经过我们。

  • 怎么做 —— 从 GitHub 仓库 bearybearbearygood/poetry-weather 拉代码跑 main.py；不熟命令行的，也可以用 WorkBuddy skill 包，一句话装好
  • 代价一 —— 每天推送的那一刻，你这台电脑要开机且联网；关机或断网那次就跳过
  • 代价二 —— 升级得自己来：诗词库扩充、版式改版都不会自动同步过去，要重新装一次
  • 好处 —— 密钥、城市、推送记录全在你自己机器上，谁也不用信

两条路互不影响，用哪个都行，想换也能随时换。

常见问题

推送成功，但屏幕没变化？

设备每个循环周期只显示一个内容。如果你的循环任务里还放了别的内容，诗词要轮到它才显示。另外检查一下有没有设置「固定内容」——固定内容的优先级比循环任务高，会一直占着屏幕，循环内容轮不上。

提示推送失败怎么办？

最常见的原因是第一步没做——循环任务里没有「图像 API」槽位。其次是 API 密钥或设备序列号抄错了，可以对照指南重新核对一遍，再注册一次。

天气数据是哪来的？准不准？

用的是彩云天气，按你注册时选的城市坐标获取，每天推送时实时拉取。温度、湿度、空气质量和当天天气状况都会影响选诗。

我的 API 密钥安全吗？

实话实说：密钥在服务端是明文保存的，这个服务也没有安全认证。但它能做的事很有限——只能往你的设备推内容，读不到你的账号或其他数据，而且你随时能在 Dot. App 里删掉它，立刻失效。怎么权衡，见上面的数据与密钥说明；不想交密钥就走自建那条路。

能给多台设备订阅吗？

可以。每台设备用各自的设备序列号注册一次就行，城市可以分别设置。

不想用了怎么取消？

打开你的管理链接，点「注销订阅」，推送立即停止，订阅记录也会删除。之后想再用随时重新注册。

拿到 API 密钥和设备序列号，就可以开始了。
